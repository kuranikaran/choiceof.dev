The project does not currently define a responsible disclosure process. 
I recommend adopting a SECURITY.md file with the following minimal policy:

- Security issues should be reported privately via GitHub Security Advisories (preferred) or by email.
- Please avoid filing public GitHub Issues for vulnerabilities.
- Acknowledge receipt of vulnerability reports within 72 hours.
- Provide an estimated timeline for remediation and release of security patches.
- Avoid sharing sensitive vulnerability details until a fix has been released.
- Follow semantic versioning on security releases and document fixes in release notes.

This ensures proper triage, coordinated disclosure, and protects users of the project.
